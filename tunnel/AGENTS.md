# Правила восстановления маршрутов

- После перезагрузки VPS российские IPv4-маршруты должны автоматически возвращаться в таблицу `100` через интерфейс из `/etc/iva/tunnel.env` (WireGuard: `wg0`, SSH: `ivasocks`), когда домашний выход доступен.
- Сохраняй автозапуск выбранного транспорта и `iva-ru-routes.timer`, запуск таймера после загрузки (`OnBootSec=1min`) и активации (`OnActiveSec=10s`), повтор каждые 5 минут (`OnUnitActiveSec=5min`). Если дом ещё недоступен, следующий запуск должен повторить восстановление.
- Учитывай порядок drop-in systemd: исправление `zz-startup-recovery.conf` должно загружаться после старого `override.conf`, который может сбросить триггеры пустым значением интервала.
- Для существующей установки используй `sudo bash tunnel/server/repair-routes-timer.sh`: он сохраняет копию своего drop-in, включает таймер и запускает проверку маршрутов без перезапуска транспорта.
- После изменений проверяй автозапуск транспорта, активность таймера, результат сервиса и `ip route get 77.88.8.8`. При доступном доме ожидаются интерфейс туннеля и `table 100`.
- Сохраняй существующую проверку доступности домашнего выхода и исключения для ответов на входящие соединения через WAN. Секреты не выводи и не коммить.
