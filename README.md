# iva-runet

Российские сайты для [Ивы](https://github.com/smixs/iva-agent) на зарубежном VPS.

- **Российский IP** — трафик к российским сайтам идёт через ваш дом или офис (роутер, компьютер или Android-телефон), остальной — напрямую.
- **Браузер `ruweb`** — для сайтов, которые не отдают страницу простому запросу: постоянный профиль, человеческий темп, остановка при блоке.
- **Camoufox** — второй движок `ruweb` для сайтов, которые распознают серверный Chrome (Самокат, Перекрёсток, Ozon): Firefox с отпечатком, подменённым на уровне браузера. Команды те же.

## Установка

Скажите Claude Code на сервере (или Иве):

> Настрой по SETUP.md: `<ссылка на этот репозиторий>`

Команды с `sudo` и `iva plugin add` агент даст вам готовыми.

Белый IP не нужен. Если VPS в России — ставьте только плагин.

## Что открывается (замер с домашнего IP)

| Как | Сайты | Время на страницу |
|---|---|---|
| обычный запрос | Госуслуги, госзакупки, Лавка, ВкусВилл | < 1–7 с |
| браузер | Яндекс Маркет | ~15 с |
| браузер с прогревом | Wildberries | первый раз ~1.5 мин, дальше ~15 с |
| строгий режим | Авито | 20–60 мин на задачу, с перерывами |
| Camoufox | Ozon (поиск проверен); Самокат, Перекрёсток — открывались, но после частых заходов за день ServicePipe стал показывать проверку и ему | 8–22 с |
| не открываются | Купер, Мегамаркет — капча «я не робот» даже в Camoufox; её Ива не решает | — |

## Если сайт просит «я не робот»

Ива капчу не решает. Она откроет эту страницу на сервере и пришлёт команду; проверку проходите вы, один раз:

1. На компьютере или телефоне: `ssh -N -L 5900:localhost:5900 <пользователь>@<сервер>` (команду пришлёт Ива).
   На Android — VNC-клиент со встроенным SSH-туннелем, например bVNC.
2. VNC-клиент → `localhost:5900`, ваш пароль VNC (задаётся один раз: `x11vnc -storepasswd ~/.iva-browser/vnc.pass`).
3. В окне браузера пройдите проверку, при желании войдите в аккаунт сайта, и напишите Иве «готово».

Окно доступно только через SSH (слушает localhost) и закрывается само через 2 часа.

## Требования

Debian/Ubuntu, sudo, Ива с `agent-browser`, от 1 ГБ свободной памяти для Chrome. Для Camoufox — ещё ~2 ГБ памяти и ~3.5 ГБ на диске;
если их нет, `ruweb setup` его не ставит, остальное работает. Chrome и Camoufox не работают одновременно.

Под ваш сервер плагин подстраивается сам при первом запуске (`ruweb setup`): лимиты памяти, ставить ли Camoufox, какой IP видят российские сайты.
