# iva-runet

Плагин для [Ивы](https://github.com/smixs/iva-agent), который учит её работать с российскими сайтами и магазинами,
когда сама Ива живёт на зарубежном сервере.

## Зачем это нужно

Ива обычно работает на зарубежном VPS. Российские сайты такой сервер не любят: одни не открываются вовсе,
другие показывают «вы робот?», третьи отдают пустую страницу. Обычный поиск Ивы плохо находит российские магазины и цены.

С этим плагином Ива:

- ходит на российские сайты с **вашего домашнего российского IP** (через туннель к дому), а не с адреса сервера;
- открывает сложные сайты **настоящим браузером** в человеческом темпе — так, чтобы её не принимали за бота;
- если сайт всё-таки просит капчу — **присылает вам ссылку**, вы проходите проверку пальцем с телефона, Ива продолжает;
- **ищет товары и сравнивает цены** на Яндекс Маркете, Wildberries и в продуктовых сетях и собирает корзину —
  а оформляете и оплачиваете вы сами.

## Что можно попросить у Ивы

Пишите обычными словами в Telegram — как попросили бы человека.

**Найти товар**

> Найди термокружку 500 мл

> Найди на Wildberries кроссовки 42 размера, покажи пять вариантов

> Найди на Авито щебень в Петербурге

Ива пришлёт список: название, цена, ссылка и картинка каждого товара.

**Где что купить и где дешевле**

> Где дешевле этот пылесос: Маркет, WB или Ozon?

> Где дешевле Coca-Cola 1 л: Лавка, Магнит, Дикси?

> Найди №2 дешевле и покажи отзывы

Ива ищет **тот же самый** товар (бренд, модель, объём) в других магазинах и пересказывает отзывы: плюсы, минусы, на что жалуются.

**Собрать корзину**

> Бери №2, положи в корзину

> Собери корзину во ВкусВилле: кефир, творог 5 %, бананы, хлеб

> Собери продукты на неделю в Лавке по этому списку

Ива кладёт товары в корзину и присылает **ссылку на корзину и сумму**. Оформляете и оплачиваете вы сами — Ива на этом останавливается.

**Ещё**

> Следи за ценой на этот товар и скажи, если подешевеет

Каждый следующий шаг — только по вашему слову: после поиска Ива не полезет в отзывы и корзину, пока вы не попросите.

## Из чего состоит

| Часть | Простыми словами | Где лежит |
|---|---|---|
| Навык `ru-web` | Браузер Ивы для российских сайтов: поиск по рунету, чтение страниц, обход «нет соединения», капча по ссылке | `plugin/skills/ru-web/` |
| Навык `market-order` | Покупки: Маркет, Wildberries, продукты — поиск, сравнение, отзывы, корзина | `plugin/skills/market-order/` |
| MCP ВкусВилла | Официальное подключение ВкусВилла: товары, состав, акции, корзина — без браузера | `plugin/mcp.json` |
| Туннель | Российский IP для сервера через ваш роутер, компьютер или телефон дома. Не нужен, если сервер в России | `tunnel/` |

Как Ива выбирает путь на сайт — сама, по порядку:

1. **Быстрый запрос** (как браузер, но без браузера, 1–5 с) — для большинства сайтов.
2. **Браузер Chrome** — если сайт рисует страницу скриптом или не отдаёт её простому запросу.
3. **Браузер Camoufox** (особый Firefox) — если сайт распознаёт серверный Chrome.
4. **Вы** — если сайт требует капчу: Ива присылает ссылку.

Какой сайт каким путём открывается, Ива запоминает и в следующий раз идёт сразу правильным.

## Что нужно

- Сервер с Ивой: Debian или Ubuntu, доступ `sudo` (команды будете запускать вы).
- Память: от 1 ГБ свободной для Chrome; для Camoufox — ещё ~2 ГБ памяти и ~3.5 ГБ диска (без них плагин работает, но без Camoufox).
- Если сервер **не в России** — что-то дома, что всегда включено: роутер (OpenWrt, Keenetic, MikroTik), Raspberry Pi или мини-ПК,
  компьютер или Android-телефон на зарядке. Белый IP дома не нужен.
- Для капчи с телефона — домен с HTTPS на сервере через Caddy (бесплатно подойдёт `<ip>.sslip.io`). Без него капча проходится
  через VNC-клиент на компьютере — работает, но неудобно.

## Установка

Удобнее всего поручить установку **Claude Code или Codex на сервере** — им нужен терминал, `sudo` и право перезапустить Иву.
Откройте его на сервере с Ивой и скажите:

> Настрой по SETUP.md: `https://github.com/Entset/iva-runet`

Агент пройдёт шаги по порядку и после каждого проверит, что всё работает. От вас понадобится:

- ответить на несколько вопросов (что есть дома, нужны ли госсайты);
- запустить команды с `sudo`, которые он даст готовыми;
- настроить дома роутер или устройство по инструкции, которую он покажет;
- подтвердить включение MCP ВкусВилла (Ива при этом перезапустится).

Самой Иве ставить плагин не стоит: `sudo` у неё нет, плагин с MCP она может только предложить вам кнопкой в Telegram
(`iva plugin propose`), а при включении MCP она перезапускается и обрывает свою же задачу.
Если сервер уже в России и туннель не нужен — Ива справится с этим предложением сама.

Подробная инструкция для агента — [SETUP.md](SETUP.md). Туннель для дома:

| Что у вас дома | Инструкция |
|---|---|
| Роутер OpenWrt | [openwrt](tunnel/home/openwrt.md) |
| Keenetic, MikroTik | [other-routers](tunnel/home/other-routers.md) |
| Raspberry Pi, мини-ПК, Linux, включённый всегда | [linux](tunnel/home/linux.md) |
| Компьютер Windows или macOS, включённый всегда | [ssh-any-device](tunnel/home/ssh-any-device.md) |
| Android-телефон на зарядке | [android](tunnel/home/android.md) |

## Если сайт просит «я не робот»

Ива капчу не решает и не обходит. Она открывает страницу у себя и присылает в чат короткую одноразовую ссылку:

1. Откройте ссылку — окно браузера Ивы откроется прямо в браузере телефона, ничего ставить не нужно.
   Видна полоса экрана вокруг капчи; если мелко — поверните телефон горизонтально.
2. Пройдите проверку пальцем: зажмите ползунок и тяните. Можно заодно войти в аккаунт сайта.
3. Напишите Иве «готово» — она закроет окно и продолжит.

Пройденная проверка запоминается и сохраняется после перезапуска браузера, так что капча нужна редко.
Ссылка живёт до «готово», но не дольше 30 минут. Пароля в ней нет — его подставляет сервер.

Если вместо капчи сайт пишет просто «Forbidden» — он запретил ваш IP на время, обычно до следующего дня. Ива скажет об этом
и не будет повторять: каждый заход продлевает запрет.

## Какие сайты открываются

Замер с домашнего российского IP, октябрь 2026.

| Как | Сайты | Время на страницу |
|---|---|---|
| быстрый запрос | Ситилинк, М.Видео, hh, Авто.ру, Дром, 2ГИС, РБК, госзакупки | 0.5–5 с |
| поиск по рунету | DuckDuckGo с регионом RU, запасной Bing (поиск Яндекса с сервера даёт капчу) | 2–3 с |
| Chrome | Яндекс Маркет | ~15 с |
| Chrome с прогревом | Wildberries | первый раз ~1.5 мин, дальше ~15 с |
| бережный режим | Авито — с перерывами, как живой человек | 20–60 мин на задачу |
| Camoufox | Ozon | 8–22 с |
| Camoufox + капча по ссылке | Перекрёсток, Ламода, Самокат, Пятёрочка, Окей, Чижик, Купер, Мегамаркет | — |

Продукты:

| Как | Магазины |
|---|---|
| MCP (официально, быстрее всего) | ВкусВилл |
| быстрый запрос | Яндекс Лавка, Глобус, Метро |
| Chrome | Магнит, Дикси, Fix Price |
| Camoufox + капча по ссылке | Перекрёсток, Пятёрочка, Самокат, Окей, Чижик, Купер |
| Camoufox, ещё не проверены | Лента, Ашан, Утконос |

Официальное подключение для ИИ-агентов есть только у ВкусВилла. У других сетей его нет, а неофициальные клиенты
([Open-Inflation](https://github.com/Open-Inflation)) внутри тоже ходят через браузер и упираются в ту же защиту.

## Безопасность и ограничения

- **Оплата — только вы.** Ива не вводит карту, не подтверждает 3DS, не оформляет заказ. Вход в аккаунт — только вашим кодом из SMS.
- **Ссылку на капчу не пересылайте.** Пока она жива, по ней можно управлять браузером Ивы, в том числе вашими входами на сайты.
  Не держите в браузере Ивы входы в аккаунты с привязанной картой без нужды.
- **Не частите.** Магазины с защитой ServicePipe (X5, Самокат, Окей и др.) при частых заходах запрещают IP на день.
  Ива заходит по одному сайту и только по задаче; не просите её «проверить все магазины подряд».
- **Правила сайтов.** Многие магазины запрещают автоматический доступ. Для личных покупок в человеческом темпе риск низкий,
  но гарантий нет. Если дорожите аккаунтом — заведите для Ивы отдельный.

## Что где лежит

```
plugin/                     — сам плагин (его ставит `iva plugin add`)
  plugin.json               — название и описание
  mcp.json                  — подключение ВкусВилла
  skills/ru-web/            — браузер ruweb: SKILL.md (инструкция Иве) и scripts/
  skills/market-order/      — покупки: SKILL.md, references/ (подробности по площадкам), scripts/
tunnel/server/              — скрипты туннеля на сервере
tunnel/home/                — инструкции для дома: роутеры, компьютер, телефон
SETUP.md                    — пошаговая установка для агента (Claude Code / Codex)
```

Данные плагина на сервере — в `~/.iva-browser/` (профили браузеров, список сайтов, логи) и `~/.config/market-order/` (настройки покупок).

## Удаление

- Плагин: `iva plugin remove runet`, строка в `~/iva/data/custom/agent/instructions/rules.md`, `rm -rf ~/.iva-browser`.
- Туннель: `sudo bash tunnel/server/rollback.sh` и блок «Откат» в инструкции для дома.
