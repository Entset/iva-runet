# iva-runet

Российские сайты и магазины для [Ивы](https://github.com/smixs/iva-agent) на зарубежном VPS.

Это **плагин Ивы** (`plugin/`, имя `runet`). Внутри:

| Часть | Что делает |
|---|---|
| навык `ru-web` | браузер `ruweb`: поиск по рунету, чтение страниц, антибот-сайты, капча владельцем по ссылке |
| навык `market-order` | Яндекс Маркет, Wildberries, продуктовые сети: поиск → дешевле → отзывы → ссылка на корзину, оплату нажимает владелец |
| MCP `vkusvill` | официальный [MCP ВкусВилла](https://habr.com/ru/post/981866): товары, КБЖУ, акции, ссылка на корзину |
| `tunnel/` | российский IP для сервера через ваш дом (не часть плагина, ставится отдельно) |

- **Российский IP** — трафик к российским сайтам идёт через ваш дом или офис (роутер, компьютер или Android-телефон), остальной — напрямую.
- **Авто-выбор режима** — `ruweb search` ищет по рунету (DuckDuckGo с регионом RU, запасной Bing ru-RU), `ruweb fetch` читает страницы:
  сначала быстрый HTTP с TLS-отпечатком настоящего Chrome ([curl_cffi](https://github.com/lexiforest/curl_cffi), идея уровней — из [Scrapling](https://github.com/D4Vinci/Scrapling)),
  при антиботе — браузер, при блоке Chrome — Camoufox. Сайт запоминается в `sites.txt`. Поиск и HTTP работают параллельно с браузером.
- **Браузер `ruweb`** — для сайтов, которые не отдают страницу простому запросу: постоянный профиль, человеческий темп, остановка при блоке.
- **Camoufox** — второй движок `ruweb` для сайтов, которые распознают серверный Chrome (Самокат, Перекрёсток, Ozon): Firefox с отпечатком, подменённым на уровне браузера. Команды те же.

## Установка

Скажите Claude Code на сервере (или Иве):

> Настрой по SETUP.md: `<ссылка на этот репозиторий>`

Команды с `sudo` и `iva plugin add` агент даст вам готовыми.

| Как | Магазины |
|---|---|
| MCP | ВкусВилл |
| HTTP | Яндекс Лавка, Глобус, Метро |
| Chrome | Магнит, Дикси, Fix Price |

Готовых MCP/API у других сетей нет; неофициальные клиенты ([Open-Inflation](https://github.com/Open-Inflation)) внутри тоже
ходят через Camoufox — с того же IP упираются в ту же защиту. Частые заходы на сайты ServicePipe дают бан IP на день
(«Forbidden» без капчи) — Ива заходит по одному сайту и только по задаче.

## Если сайт просит «я не робот»

Ива капчу не решает. Она откроет эту страницу на сервере и пришлёт в чат одноразовую ссылку:

1. Откройте ссылку — окно браузера Ивы откроется прямо в браузере телефона или компьютера (noVNC, ничего ставить не нужно).
   Видна полоса экрана вокруг капчи; если мелко — поверните телефон горизонтально.
2. Пройдите проверку пальцем (зажать и тянуть — долгое нажатие работает как обычное) или мышью, при желании войдите в аккаунт
   сайта, и напишите Иве «готово». Пройденная проверка сохраняется и после перезапуска браузера.

Ссылка работает через HTTPS-домен Caddy на сервере (маршрут добавляется на время проверки через локальный API Caddy, без sudo),
короткая (`https://<домен>/vnc-<токен>`), пароль подставляет сервер — в чате его нет. После «готово» или через 30 мин окно и ссылка закрываются.
Кто получит ссылку, может управлять браузером, пока она жива, — не пересылайте её.
Нет Caddy с HTTPS-доменом — Ива пришлёт вариант через `ssh -L` и VNC-клиент (пароль будет в сообщении).

## Требования

Debian/Ubuntu, sudo, Ива с `agent-browser`, от 1 ГБ свободной памяти для Chrome. Для Camoufox — ещё ~2 ГБ памяти и ~3.5 ГБ на диске;
если их нет, `ruweb setup` его не ставит, остальное работает. Chrome и Camoufox не работают одновременно (память); поиск и HTTP-уровень (~40 МБ, curl_cffi в своём venv) — в любое время.

Под ваш сервер плагин подстраивается сам при первом запуске (`ruweb setup`): лимиты памяти, ставить ли Camoufox, какой IP видят российские сайты.
