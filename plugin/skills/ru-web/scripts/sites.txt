# Формат: домен [warm|strict|home] [expect=<css>]  # заметка
#   без флага — постоянный профиль на сервере, обычный темп;
#   warm      — перед первым заходом прогрев профиля (~1 мин раз в 3 дня) и вход с главной;
#   strict    — как warm + сессии с перерывами, 09–22 МСК, ≤40 переходов в час;
#   home      — только в настоящем Chrome дома/в офисе (tunnel/home/browser.md); без него — HOME_DOWN.
# Ива дописывает сюда сама, если обычный запрос получил блок (`ruweb mark <домен>`).
