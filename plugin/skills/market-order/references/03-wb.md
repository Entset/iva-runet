# 03. Wildberries: браузер, гость/аккаунт, корзина, вход, удаление

Проверено разведкой 2026-10-26 (см. 01-preflight): главная, поиск
(`?search=`), карточка (`/{артикул}/detail.aspx`), «Добавить в корзину»
гостем — ок; корзина показывает товар и «Войти и оформить»; удаление крестиком — ок.
Оформление заказа НЕ проверено — это шаг владельца.

## MCP не работает

`wb_search`/`wb_card`/`compare_prices`-WB с сервера отдают **HTTP 403** (IP сервера,
известно с 2026-10-26). WB — **только браузером через ruweb** (wildberries.ru в
sites.txt как sensitive). Поиск:

`market-order.sh search wb "запрос"` = `ruweb open https://www.wildberries.ru/catalog/0/search.aspx?search=<запрос>`

Карточка: по ссылке из выдачи или `https://www.wildberries.ru/catalog/<артикул>/detail.aspx`.

## Два режима корзины

- **GUEST** (по умолчанию): «Добавить в корзину» работает без входа, корзина
  `https://www.wildberries.ru/cartorder`. Дальше Ива — ссылка на корзину + сумма + СТОП:
  кнопку **«Войти и оформить»** нажимает только владелец.
- **AUTH** (вход владельца): корзина висит на его аккаунте; вход один раз по телефону
  + SMS-коду, потом cookies в `state-wb.json`.

## Вход WB (AUTH; только по явному запросу владельца или по его номеру в конфиге)

1. `market-order.sh login open` — открыть главную, нажать «Войти», ввести телефон
   из `PHONE_WB` (`~/.config/market-order/config.env`).
2. **Код из SMS присылает владелец в чат.** Ива не запрашивает SMS сама, не читает
   чужие чаты и не угадывает код.
3. `market-order.sh login enter <КОД>` — ввести, проверить: кнопка «Войти» пропала,
   в профиле видно аккаунт.
4. `market-order.sh state-save` — cookies → `~/.config/market-order/state-wb.json`
   (chmod 600, бэкап предыдущего). Файл не коммитить и в чат не вставлять.

Если на любом шаге капча/«подтвердите, что вы не робот»/доп. SMS-подтверждение:
**СТОП, не обходить ничего**, сообщить владельцу (05-errors.md).

## Удаление из корзины

Крестик у товара в `cartorder` → проверить пустоту повторным snapshot. Тестовые
товары убирать всегда; чужие (на аккаунте владельца) — не трогать.

## Известные дыры

- WB API с сервера 403 → любое слежение за ценой WB — реже (см. 04-monitor.md) и браузером.
- Цены «с WB-кошельком»/со скидкой по клику — считать цену покупки только
  `price_rub`-подобную дневную цену на карточке, скидочные обещания не называть.
## Проверено живьём 2026-10-26 (реальный вход владельца)

- Старт: `https://www.wildberries.ru/lk` редиректит на `id.wb.ru/login` (WB ID, OAuth).
  Форма: кнопка «Номер телефона» + `textbox "000 000-00-00"` (10 цифр БЕЗ 8/+7),
  затем кнопка «Получить код».
- Код приходит на 6 отдельных `textbox` — работает один `type "@<первый>" "719254"`
  (автопереход между полями), отдельно по цифрам не нужно.
- После кода — экран согласия «Wildberries получит доступ к данным WB ID» →
  кнопка **«Принять»** (это обычный OAuth-consent, не оплата; нажимать можно).
- Успех: редирект на `wildberries.ru/lk`, в шапке имя владельца, вкладки
  «Заказы / Профиль / Корзина».
- Счётчик «1 Корзина» может быть устаревшим бейджем гостевой корзины: реальное
  состояние смотреть по тексту страницы (`eval "document.body.innerText"`) —
  при пустой корзине там «По Вашему запросу ничего не найдено» + рекомендации.
- `state save` сохраняет 362 cookies (~1.1 МБ) за ~3 с.
- БАГ исправлен: в `state_save` стоял `timeout 40 AB state save` — `timeout` не
  запускает shell-функцию, сохранение молча падало (exit 12). Теперь без `timeout`.
