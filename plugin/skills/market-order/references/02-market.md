# 02. Яндекс Маркет: cookies, карточка, корзина, удаление

Проверено разведкой 2026-10-26 (см. 01-preflight): полный цикл «главная → карточка →
«В корзину» → корзина → удаление» пройден, корзина оставлена пустой.

## Вход (cookies)

- Свой state Ивы: `~/.config/market-order/state.json` — сначала подложить его.
- Если его нет — cookies Яндекса переиспользуются из
  `~/.config/yandex-taxi-skill/state.json` (тот же yandex-аккаунт): это
  живой вход владельца, НЕ перезаписывать этот файл, только читать из него:
  `agent-browser --session ruweb --profile ~/.iva-browser/profile state load <файл>`.
- Если и после подкладывания Маркет показывает «Войти»: НЕ перелогинивайся сама и
  не пробуй регистрироваться. Спросить владельца — он входит сам (ссылка
  `ruweb open https://market.yandex.ru/`), после его входа → `market-order.sh state-save`.

## Маршрут (все переходы через `ruweb open`, не голым `ab open`)

1. Поиск: MCP `yandex_search` (первый выбор) → браузером
   `https://market.yandex.ru/search?text=<запрос>`.
2. Карточка: из результата MCP `yandex_card` (отзывы, звёзды) или по ссылке из выдачи.
3. Кнопка **«В корзину»** → клик по свежему ref из snapshot.
4. Корзина: `https://market.yandex.ru/my/cart`.

## Корзина и СТОП

- В корзине читать snapshot: товары, цена, сумма.
- Если видна кнопка **«Перейти к оформлению»** — это нормально: она и ждёт владельца.
  Ива НЕ нажимает её и «Оплатить»/«Заказать» тоже. Ссылка на корзину + сумма + стоп
  (`market-order.sh cart market <url>` печатает `STOP_BEFORE_CHECKOUT` сам).
- Кнопка «Оплатить»/ввод карты/3DS/SMS — никогда. Оформление — только владелец.

## Удаление товара

- В корзине у строки товара кнопка **«Удалить»** → клик по ref → убедиться, что строка
  пропала (повторный snapshot; «Корзина пуста» = чисто).
- Товары, стоявшие в корзине до нашего визита, НЕ трогать; свои тестовые — удалить
  до состояния «пусто».

## Ошибки

- 403/капча при `ruweb open` → навык `ru-web`: стоп, cooldown, владельцу не писать
  отдельно, а доложить в итоге хода. См. 05-errors.md.
- «В корзину» нет → нет в наличии / селлер-вариант: посмотри другие офферы на карте
  или поиск по другому слову. См. 05-errors.md.
