# 01. Preflight: браузер, ruweb, MCP

## MCP (первый выбор для поиска и цен)

Коннектор `marketplace` (read-only, без ключей). Проверка: `marketplace_sources` →
mounted должен содержать `yandex` и `wildberries`.

- `yandex_search`, `yandex_card` (с отзывами и распределением звёзд) — работают с сервера (проверено 2026-10-26).
- `compare_prices` — работает; WB-источник может вернуть 0 results при блоке card.wb.ru
  (см. 03-wb). Плюсовую цену `price_with_*` не называть ценой покупки.
- WB-цены/карточки через MCP (`wb_card`, `wb_search`) — HTTP 403 с сервера (2026-10-26).
  Пока так — WB только браузером (03-wb), слежение по WB — реже и через браузер.

## Браузер: правила

- Секретный/антибот-контекст: ruweb из навыка ru-web того же плагина (`data/custom/plugins/<плагин>/skills/ru-web/scripts/ruweb`).
  market.yandex.ru в sites.txt НЕ значится, wildberries.ru — значится как sensitive:
  в любом случае открывать **через `ruweb open URL`** — это даёт тёплый профиль,
  человеческий темп и детектор блоков. Прямой `agent-browser open market.yandex.ru`
  из голой сессии получает 403 (проверено 2026-10-26) — не повторять.
- Команды после `open`: читать через `snapshot`/`screenshot` тем же ruweb-сеансом
  (`agent-browser --session ruweb --profile ~/.iva-browser/profile --executable-path
  <...>/chrome --headed --args "--no-sandbox" ...`). Кликать только по свежим refs.
- Навигации — через `ruweb open` (учёт темпа), а не голым `ab open`.
- Блок/капча в ruweb → `ru-web` навык: стоп, сообщить владельцу, не ретраить в лоб.

## Стадия (scripts/market-order.sh stage)

- `NO_MCP` — marketplace_sources не отвечает; поиск только браузером или отложить.
- `MCP_WB_DOWN` — wb API 403; для WB использовать references/03-wb.
- `NO_LOGIN` — Маркет «Войти» → 02-market (подложить state → если нет, владелец).
- `SITE_BLOCK` — 403/капча после ruweb; сайт в cooldown, не открывать до конца паузы.
- `READY` — можно искать/сравнивать/класть в корзину.

## Данные, которые проверены (2026-10-26)

- Маркет: главная, карточка, «В корзину», корзина, удаление — весь цикл пройден,
  товар удалён, корзина снова пустая.
- WB: главная, поиск (?search=), карточка (/{article}/detail.aspx), «Добавить в корзину»
  как гость — ок; корзина показывает товар и «Войти и оформить»; удаление крестиком ок.

  телефону/SMS; на Маркете адрес/окно оплаты/3DS).
