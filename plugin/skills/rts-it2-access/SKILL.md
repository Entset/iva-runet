# it2.rts-tender.ru: имущественные торги

Для любой ссылки или задачи на этом домене использовать этот порядок вместе
с навыком `ru-web`. Когда владелец в контексте имущественных торгов говорит
«РТС» или «зайди на РТС» без ссылки, открывать `https://it2.rts-tender.ru/`.
Не подменять его корпоративным сайтом `www.rts-tender.ru`: это другой адрес,
успех или блокировка на нём не доказывает доступность `it2`. Явно заданные ссылки
на другие разделы РТС сохранять, не менять их молча.

## Открытие и готовность страницы

Использовать существующий браузер ruweb и его постоянный профиль через настроенный
RU-маршрут. Домен уже покрыт записью `rts-tender.ru` в `~/.iva-browser/sites.txt`.
Не начинать с web_fetch, curl, отдельного agent-browser или прямых запросов к API.

```bash
R=data/custom/plugins/runet/skills/ru-web/scripts/ruweb
"$R" open https://it2.rts-tender.ru/
"$R" snapshot -i -c
"$R" get text body
```

Стартовая Anti-DDoS-проверка может пройти автоматически: ruweb уже даёт ей
примерно 24 секунды. После `OK Имущество` приложение ещё может догружать данные.
Пустой snapshot сразу после открытия не означает блокировку: подождать загрузку
до 30 секунд и повторно прочитать страницу без повторной навигации. Список готов,
когда появились лоты либо явное сообщение об отсутствии результатов. Карточка
лота готова, когда есть номер процедуры и описание лота/цена. Один заголовок
«Имущество» доступ к данным не подтверждает. Если данные так и не появились,
сообщить об этом, не перебирать скрытые адреса и не запускать цикл перезагрузок.

## Поиск и чтение

1. На главной выбрать «Классический» через `click` по ссылке из свежего snapshot.
2. Через `type` ввести номер или название в поле «Введите наименование, номер,
   описание процедуры или лота», затем нажать «НАЙТИ».
3. Дождаться результатов, получить новый snapshot, открыть нужную карточку кликом.
   Значения `@eN` брать заново после переходов; номера ссылок не сохранять.
4. Читать текст страницы и DOM через `get text body` / `eval`. Доступны название,
   регион, цена, задаток, сроки, организатор и документы. Факты брать из текущей
   страницы. Статусы и число заявок меняются: при расхождении с письмами РТС указывать источник.
5. PDF может быть элементом без `href`: для скачивания нужен клик в браузере.
   Наличие элемента документа не означает, что файл уже скачан.

Работать последовательно в общей сессии, соблюдать паузы и ответы ruweb.
Для капчи/блокировки использовать предусмотренный навыком `ru-web` режим
`captcha <url>` и окно владельца; после его «готово» — `captcha done`.
Не очищать профиль вручную и не обходить cooldown отдельным браузером.

## Различать сбои (по трассировке 2026-11-01)

- `BUSY` означает, что общий браузер занят другой задачей, а не блокировку РТС.
  Выдержать 90 секунд без действий в этом браузере, затем повторить `open` один
  раз. Если другая задача продолжает работу, сообщить о занятости, не сбрасывать
  lock, не останавливать браузер и не делать цикл попыток.
- Диагностика туннеля: `ip route get 77.88.8.8` и `ip route get 185.179.85.15`
  (последний адрес — проверенный IPv4 it2 на 2026-11-01; при смене DNS взять свежий).
  Ожидаются `dev wg0 table 100`; также смотреть результат `iva-ru-routes.service`.
  Не считать туннель неработающим только из-за ping роутера или IP на ifconfig.me:
  российские префиксы идут через туннель, остальные направления могут идти напрямую.
- Если нужен `fetch`: `"$R" fetch --max 1500 URL` (`--max` можно ставить где угодно).
  Для it2 основной путь — `open`.
- При проверке результата не прятать код ошибки конвейером `| head`: сначала
  сохранить вывод и код ruweb, затем при необходимости сократить вывод.

## Сохранение данных по запросу

После загрузки страницы использовать соседний `scripts/export-visible.py`:

```bash
python3 data/custom/plugins/runet/skills/rts-it2-access/scripts/export-visible.py /tmp/rts-page.json
```

Путь результата должен быть новым. Скрипт читает только текущий DOM через ruweb,
не листает страницы и не обращается к API. В списке выделяет номер, название,
ссылку и первую отображаемую сумму; исходный текст сохранён для проверки.
У карточки данные в `text` и `links`, массив `lots` пустой. У элементов документов
без `href` значение `url` равно `null`. Ошибка при пустой выдаче не доказывает блок.


Проверено 2026-11-02: список, поиск по номеру, открытие карточки и экспорт JSON
работают без ручной капчи. Скачивание PDF и длительный фоновый сбор не проверены.
